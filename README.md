# Reactive Demo (Project Reactor)

Requirements: JDK 17+ and Maven.

Run:
    mvn compile exec:java -Dexec.mainClass=com.example.reactive.ReactiveDemo

Or open the folder in IntelliJ IDEA / Eclipse / VS Code and run ReactiveDemo.main().

Expected output:
    Received: 4
    Received: 16
    Received: 36
    Received: 64
    Received: 100
    Completed
